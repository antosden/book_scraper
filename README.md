# Book Scraper

Парсер книг с сайта [Books to Scrape](https://books.toscrape.com).

---

## Цель проекта
Проект предназначен для автоматического парсинга данных о книгах с сайта [Books to Scrape](https://books.toscrape.com)  
и регулярной выгрузки этих данных в файл `books_data.txt` по расписанию.
В ходе работы было необходимо продемонстрировать следующие навыки:
- Парсинг с помощью `BeautifulSoup`, `requests`;
- Настройка запуска по расписанию с помощью `schedule`;
- Написание автотестов с использованием `pytest`.

Для скорости отработки парсинга была реализована многоточность с подходом Producer/Consumer 
(Среднее время парсинга сократилось с 30 мин до 2-3 мин), а также добавлено логгирования для
удобства отладки и демонстрации промежуточных результатов

## Запуск проекта

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустить парсер:
   ```bash
   python scraper.py
   ```
   При необходимости выставить нужное время запуска в scraper.SCHEDULE_TIME (по умолчанию '19:00').
   
   Также при необходимости можно повысить уровень логгирования с INFO на DEBUG 
   (по умолчанию INFO выставлен для вывода в консоль, DEBUG - для записи в лог)


3. Результат сохранится в файл в корне проекта:
   ```
   books_data.txt
   ```
